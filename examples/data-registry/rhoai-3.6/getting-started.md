# Getting started with the Data Registry in RHOAI 3.6

This guide is now organized into [four customer steps](../README.md). Start with
[Step 1: Configure the Data Registry](../01-configure-data-registry/README.md).
The suggested path uses an RHOAI admin for Step 1 and an RHOAI user with
project `admin` permissions for Steps 2 and 3. Step 4 is optional.
